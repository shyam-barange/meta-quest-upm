# Changelog

## [2.0.0] - 2026-10-29

### Added
- **Query Mode for multi-frame localization.** `MapLocalizationManager` now exposes `queryMode`
  (`VPS-1 (Standard)` / `VPS-2 (Deep Search)`), matching `SingleFrameLocalizationManager`.

## [1.15.2] - 2026-08-06

### Added
- `queryMode` parameter (VPS-2 Deep Search) for single-frame localization.

### Changed
- Updated package dependencies.

## [1.15.0]

### Added
- Localization Hints support (hint map codes, position, floor height, radius, 2D filtering).
